# Planos de evacuación · Grupo Codere Colombia

Editor web de los planos de evacuación de las sedes de Grupo Codere Colombia (SG-SST, código CC-PLSST-04).

Este repositorio contiene **solo el programa**. No contiene planos: los layouts de cada sede están en el repositorio **privado** `actualizador-de-planos`, y el editor los lee y los guarda a través de la API de GitHub con un token personal que queda en el navegador de cada usuario.

## Uso

1. Abre la página publicada con GitHub Pages.
2. Pulsa **GitHub** y escribe la cuenta, el repositorio de datos (`actualizador-de-planos`) y tu token.
3. Elige la sede, mueve máquinas, mobiliario y equipos; las rutas y las comprobaciones se recalculan solas.
4. **Guardar versión** crea un commit en el repositorio de datos con el motivo del cambio.
5. **Descargar** genera el PDF (carta, oficio, tabloide o A3), PNG, SVG o JSON. **Imprimir** abre el diálogo de impresión del navegador.

## Actualizar el programa

Reemplaza `index.html` por la versión nueva y confirma el cambio. GitHub Pages publica la actualización en uno o dos minutos.
